# Help ACP Go Mesh Reach More Agent Builders

ACP Go Mesh is for developers who believe agent systems need real control planes: routing, lifecycle state, approval gates, observability, and local-first custody.

## How To Help

- **Star the repository** if you want protocol-native agent orchestration to exist.
- **Share a screenshot** of your mesh topology, command center, or local agent stack.
- **Open an issue** describing the agents you want coordinated.
- **Contribute an adapter** for a CLI, MCP server, browser agent, or local worker.
- **Add a protocol fixture** that makes A2A, MCP, or AG-UI compatibility easier to verify.
